# Shelter 0.8.0

This release brings external customer domains and managed application services
into the existing single-VPS control plane.

## New capabilities

- Connect external customer subdomains by CNAME inside each project, with DNS
  ownership verification, Cloudflare for SaaS certificates, and a project-scoped
  integration API. Shared applications and dedicated customer projects use the
  same domain workflow.
- Manage isolated self-hosted Supabase instances, connect public API settings
  to applications, open protected Studio, deploy Edge Functions, and perform
  encrypted backup and recovery operations.
- Configure shared outgoing SMTP with verified TLS connections and explicit
  application to instance consumers. Individual instances can override it.
- Protect administrator sign-in with an authenticator and recovery codes, and
  inspect the local security-event history.
- Use a consistent neutral interface with shared forms, dialogs, navigation,
  and light/dark themes. Existing custom branding remains supported.

## Reliability fixes

- Empty web API mutations carry typed JSON, avoiding HTTP 415 failures when a
  reverse proxy forwards an otherwise empty request with transfer framing.
- OAuth upgrades detect missing certificate permissions and preserve the active
  connection until the replacement has been validated and adopted.
- Cloudflare Access links follow the current dashboard navigation.
- Customer-domain checks use configurable public DNS resolvers, so a stale host
  resolver does not hide otherwise visible TXT proofs. Manual checks explain
  whether they are waiting on DNS, another check, or certificate issuance.
- Project networks can use an explicitly reserved private pool. Exhaustion
  preserves existing attachments and does not stop reconciliation of other
  projects.
- Worker-side ZIP extraction rechecks archive entries and expansion bounds.

## Upgrading

Back up the data volume and retain `APP_SECRET` before updating. Install the
immutable release with the verified [release installer](../RELEASES.md).
Do not replace an operator's environment file or copy a developer's Compose
override into an installation.

Existing Cloudflare OAuth clients need `ssl-and-certificates.write` added to
their allowed and required scopes, followed by **Reconnect Cloudflare** in
Shelter. Keep the current connection until the new one is adopted. New scope
defaults cannot grant permissions to an already issued token. Token users need
the equivalent zone-scoped **SSL and Certificates Edit** permission.

Cloudflare for SaaS still needs to be enabled and an active fallback selected
for the provider zone. Customer DNS normally points at the configured Shelter
primary hostname. See [external-domain setup](../EXTERNAL-DOMAINS.md).
Allow outbound DNS to the configured verification resolvers, or set
`EXTERNAL_DOMAIN_DNS_SERVERS` to the public resolvers permitted in your network.

Managed Supabase is optional. Read [its operating requirements](../SUPABASE.md)
before creating an instance, and configure [SMTP](../SMTP.md) if email sign-in is
needed. New installations do not automatically enable administrator MFA;
enroll an authenticator and store recovery codes before relying on it.

## Validation limits

The source pilot passed Cloudflare reauthorization, tunnel connectivity,
Cloudflare for SaaS fallback validation, and persistence across updates.
These checks do not replace a disposable external customer-domain test covering
DNS propagation, certificate issuance, application tenancy, and cleanup.
The remaining acceptance work and implementation contracts are recorded in
[the agent handoff](../AGENT-HANDOFF.md).
